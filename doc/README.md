# Breath Project Documentation

This directory documents the Java/Swing breathing sprite editor at a code level. It is intended for maintainers who need to understand how the UI, deformation engine, persistence, export, tutorial, and packaging workflows fit together.

## Reading Order

1. [Architecture](architecture.md) for the high-level workflows and Mermaid diagrams.
2. [Class Index](class-index.md) for one-line class responsibilities.
3. Individual class pages under [classes/](classes/) when changing a specific file.
